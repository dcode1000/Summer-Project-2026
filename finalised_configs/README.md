## finalised_configs README

This folder contains all final versions of all configs used in training truth and GN2 style models. Configs prefixed by dumper relate to the ftag-dumper software, by umami relate to umami preprocessing software and by salt relate to those used to config salt-ml software.

Configs used are compatible with:
- ftag-dumper version: 25.9.7???
- umami-preprocessing version: 0.3.1
- salt-ml version: 0.13.0
